# Build vs Buy AI: Decision Framework for Mid-Market Companies (2026)

**Author:** Damien Clothier
**Published:** 2026-05-25

## The five weighted factors

- "Urgency (Weight: 25%)"
- "Technical Complexity (Weight: 20%)"
- "Internal Capability (Weight: 20%)"
- "Budget Constraints (Weight: 20%)"
- "Strategic Importance (Weight: 15%)"

## Cost comparison (verbatim)

- In-house: "$200K-$450K (18 months)" for a minimum viable team
- Big 4 consulting: "$500K-$2M+ (18 months)"
- Mid-market consulting: "$35K-$250K (18 months)"

## Core argument

Mid-market consulting delivers "fastest time-to-value (production deployment by month 3, ROI by
month 4-6)" while presenting "lowest risk ($50K-$100K investment, 3-6 month commitment)"
compared to alternatives that either delay value significantly or create substantial financial
exposure.

## Note on the playbook's use of this source

The playbook's Section 3.4 presents a build-vs-buy table (time to value, customization, data
sovereignty, TCO, IT capability, IP risk) attributed to this source. That table does **not**
appear in this capture — the source's actual framework is the five weighted factors above,
comparing *delivery models* (in-house / Big 4 / mid-market consultancy), not *build vs. buy* as
the playbook frames it. Flag as a possible mis-citation.
